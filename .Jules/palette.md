## 2024-03-24 - Consistent Action Button Structure for Accessibility
**Learning:** In the cockpit UI, `.surface-action` buttons often rely on hover to reveal their full labels, showing only icons by default. When the internal structure is omitted (e.g. `<button>🔤 Update</button>`), screen readers may read the literal text or emoji unpredictably, and the visual label expansion transition fails.
**Action:** Always wrap `.surface-action` content in `<span class="surface-action__icon" aria-hidden="true">` and `<span class="surface-action__label" aria-hidden="true">` inner spans, and apply the descriptive text to the parent `<button>` using `aria-label` and `title` attributes. This ensures proper screen reader announcements, consistent hover tooltips, and enables the intended CSS width transition.
