## 2025-03-28 - Optimizing Byte Array to Base64 Conversion
**Learning:** Converting large byte arrays (e.g., video frames, audio chunks) to base64 using a byte-by-byte loop (`binary += String.fromCharCode(b)`) introduces a severe performance bottleneck due to O(N^2) string concatenation overhead in some JS engines. Alternatively, applying `String.fromCharCode.apply(null, array)` to the entire array at once can cause "Maximum call stack size exceeded" errors.
**Action:** When converting large byte arrays to Base64 in JavaScript, always process the array in chunks (e.g., 8192-byte chunks) using `String.fromCharCode.apply(null, chunk)` and concatenate the resulting strings. This method avoids call stack size limits and is typically ~10x faster than byte-by-byte concatenation.
