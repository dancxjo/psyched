## 2024-04-20 - Batch retrieval of memory metadata
**Learning:** Graph metadata retrieval during memory recall previously iterated over each recalled vector ID, generating an N+1 query problem with Neo4j. Since the GraphStoreProtocol and Neo4jGraphStore didn't support batch retrieval, every individual semantic memory fetch triggered a full network roundtrip to the graph database.
**Action:** Introduced a `fetch_memories(memory_ids)` interface to the GraphStoreProtocol. Implemented this in the Neo4jGraphStore using the `UNWIND` Cypher clause, returning a batched `Mapping[str, Mapping[str, Any]]`. Refactored `MemoryService.recall` to batch fetch all necessary metadata for the retrieved vectors at once, drastically reducing graph database latency and overhead during vector-recall resolution.
